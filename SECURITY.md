# Security Policy

## Reporting a Vulnerability

Otaman takes security seriously. If you discover a security vulnerability, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead, email **security@otaman.ai** with:
- Subject line beginning with `[otaman-security]`
- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact

We aim to acknowledge receipt within 5 business days and will work with you on a fix timeline.

## PGP Key

A PGP key is available on request. Contact security@otaman.ai to receive it.

## Security Updates

We recommend:
- Keeping Otaman updated to the latest version
- Enabling security notifications on this repository (GitHub "Watch" → Custom → Security alerts)
- Reviewing the CHANGELOG for security-related fixes

## Scope

This security policy applies to:
- Otaman Community Edition (CE) — all public repositories
- Otaman Enterprise Edition (EE) — covered under customer support agreements

For EE security issues, customers should contact their designated support contact.

## Past Security Advisories

Security advisories will be published here as they are resolved and announced.
